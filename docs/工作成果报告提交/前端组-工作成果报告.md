## 3. 解决方案与实现

### 3.1 多租户前端（新建）

这部分是从零写的，对接 SaaS 组后端接口：

```
features/tenant/
  ├── api/tenant.ts        — switchTenant / getTenants / createTenant / getMembers
  ├── hooks/useTenant.ts   — 列表拉取 + 切换逻辑
  ├── pages/TenantManagePage.tsx — 管理页面
  ├── routes.tsx
  └── types.ts
```

切换租户：调后端 `switch-tenant` → 拿新 session → 清缓存 → reload 页面（断 SSE + 清状态）。

### 3.2 SSE 流式展示（在已有基础上补）

审核详情页之前已经有了，但结果只能等审核完一次性拉。我补了 SSE 实时消费：

- `auditDetail.ts`：用 `fetch + ReadableStream` 连 SSE（不用 EventSource，因为要带 Authorization 和 Last-Event-ID Header）
- `useAuditTask.ts`：处理 `finding_added` / `finding_updated` / `progress` / `phase` 等事件，按 `riskId` 去重（后端 Java 会双发 `finding_added` + `issue`）
- `mapFinding.ts`：后端 Finding → 前端 AuditIssue 映射
- 断线重连：指数退避 1s → 2s → 4s → 8s → 16s，最多 5 次；重连时带 `Last-Event-ID` 让后端回放

### 3.3 链路高亮（在已有基础上改）

PdfPreview.tsx 原来只有文本匹配高亮（遍历 DOM span 做子串匹配）。后端已经返回了 BBox 坐标但前端没用。我加了 `highlightBboxes` 方法：

- 后端返回 PDF points 坐标 → 前端按 `scaleFactor = renderedWidth / nativeWidth` 换算成 DOM 像素
- BBox 带 `page` 字段，按页分组渲染到各自页面的 overlay 层（修了跨页高亮的 bug）
- 后端 page 是 0-based，前端 +1 转换
- 加了 `VITE_HIGHLIGHT_MODE`（auto / bbox / text），auto 模式下 bbox 为空时回退文本匹配

### 3.4 PR 自审修复

| 问题 | 改法 |
|------|------|
| token 刷新并发踢下线 | `refreshPromise` 单例，多 401 共享同一个 refresh |

| user_id 类型不兼容 | `number` → `number \| string` |

| 残留 console.log | 删 6 处 |
| mock 租户列表不刷新 | 返回新数组引用 `[...mockTenants]` |
