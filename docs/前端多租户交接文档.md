# 前端多租户接口速查

后端基线：`luomo-dev` / `adf7478`。

参考：[接口契约](../backend-java/docs/多租户接口契约.md)｜[OpenAPI](../backend-java/docs/tenant-openapi.json)

## 接入规则

- 除登录外，请求都带 `Authorization: Bearer <token>`。
- `tenant_id`、`user_id` 等 ID 在前端按字符串保存。
- 浏览器不要发送 `X-Tenant-Id`、`X-User-Id` 或 `X-Internal-*`。
- 切租户成功后整体替换登录会话，清掉旧租户缓存和 SSE 连接。
- 租户接口使用 snake_case；旧业务接口多为 camelCase，分页数据通常在 `records`。

## 统一响应

普通接口返回：

```json
{
  "code": 200,
  "msg": "success",
  "data": {},
  "timestamp": 1786019400123
}
```

下载、预览和 SSE 不使用这层 JSON 包装。

## 认证接口

| 方法 | 路径 | 请求 | 成功时 `data` |
|---|---|---|---|
| POST | `/api/auth/login` | JSON：`username`、`password` | `AuthSession` |
| POST | `/api/auth/refresh` | Bearer，无请求体 | 新 `AuthSession`，旧 token 失效 |
| POST | `/api/auth/logout` | Bearer，无请求体 | 空 |
| POST | `/api/auth/switch-tenant` | Bearer，JSON：`tenant_id` | 新 `AuthSession`，旧 token 失效 |

登录：

```json
{
  "username": "alice",
  "password": "password"
}
```

切租户：

```json
{
  "tenant_id": "20002"
}
```

`AuthSession` 关键字段：

```json
{
  "token": "eyJ...",
  "token_type": "Bearer",
  "expires_in": 86400,
  "session_version": 3,
  "user_info": {
    "user_id": "10001",
    "username": "alice",
    "real_name": "Alice"
  },
  "current_tenant": {
    "tenant_id": "20001",
    "tenant_code": "acme-bid",
    "name": "Acme 招标团队",
    "status": "ACTIVE",
    "role": "ADMIN",
    "permissions": [],
    "is_current": true
  },
  "tenants": []
}
```

前端每次登录、刷新、切租户后，都直接用新的 `AuthSession` 覆盖旧状态。

## 租户和成员

| 方法 | 路径 | 请求 | 成功时 `data` |
|---|---|---|---|
| GET | `/api/tenants` | Bearer | `current_tenant_id`、`items` |
| POST | `/api/tenants` | Bearer，JSON | 新租户对象 |
| GET | `/api/tenants/current` | Bearer | 当前 `TenantSummary` |
| GET | `/api/tenants/{tenantId}/members?page=1&size=20` | Bearer | `page`、`size`、`total`、`items` |

创建租户：

```json
{
  "name": "Acme 招标团队",
  "tenant_code": "acme-bid",
  "plan_code": "STANDARD",
  "settings": {
    "timezone": "Asia/Shanghai"
  }
}
```

不要提交 `tenant_id`、`owner_user_id`、`status` 或 `version`。创建成功后，当前用户成为该租户的 `OWNER`。

成员项主要字段：`member_id`、`tenant_id`、`user_id`、`username`、`real_name`、`role`、`permissions`、`status`、`joined_at`、`last_seen_at`。

## KnowledgeFile

基础路径：`/api/knowledge-files`

| 方法 | 路径 | 请求 | 成功时返回 |
|---|---|---|---|
| GET | `/api/knowledge-files` | `category`、`tags`、`applicable_scope`、`page`、`size` | `data.total`、`data.records` |
| GET | `/api/knowledge-files/search` | `keyword`、`page`、`size` | `data.total`、`data.records` |
| POST | `/api/knowledge-files/upload` | multipart：`file`、`category` 必填 | 空 `data` |
| PUT | `/api/knowledge-files/{fileId}` | multipart：`category` 必填，`file` 可选 | 空 `data` |
| PATCH | `/api/knowledge-files/{fileId}/status` | `{"status": 1}` | 空 `data` |
| DELETE | `/api/knowledge-files/{fileId}` | 无请求体 | 空 `data` |
| GET | `/api/knowledge-files/{fileId}/download` | 无请求体 | 文件二进制 |
| GET | `/api/knowledge-files/{fileId}/preview` | 无请求体 | PDF 二进制 |

列表项使用 camelCase，例如 `fileName`、`fileSize`、`fileType`、`applicableScope`、`uploadTime`。下载和预览必须走接口，不要直接使用数据库里的 `filePath`。

## AuditTask

| 方法 | 路径 | 请求 | 成功时 `data` |
|---|---|---|---|
| POST | `/api/audit-tasks` | JSON | `{ "taskId": "..." }` |
| GET | `/api/audit-tasks/{taskId}` | 无请求体 | 状态、阶段、进度、问题数量 |
| POST | `/api/audit-tasks/{taskId}/recover` | 无请求体 | `boolean` |
| GET | `/api/audit-tasks/{taskId}/result?page=1&size=20` | `sinceIssueNo` 可选 | 审核结果和 `issues` |
| GET | `/api/audit-tasks/{taskId}/stream` | `Accept: text/event-stream` | SSE |
| GET | `/api/audit-tasks/{taskId}/blocks?ids=...` | `ids` 必填 | PDF 坐标数组 |
| GET | `/api/audit-tasks/count-audit` | 无请求体 | 本周审核数 |

创建审核任务：

```json
{
  "bidId": 501,
  "enabledAgents": [],
  "forceRefresh": false
}
```

不要发送 `tenantId`。服务端从当前会话写入租户。创建成功后先轮询状态；需要实时进度时再连接 SSE。

## 错误处理

| HTTP / `error_code` | 前端动作 |
|---|---|
| 401 `AUTH_REQUIRED`、`AUTH_INVALID` | 尝试刷新一次；失败后清登录状态 |
| 401 `TENANT_SESSION_STALE` | 不使用旧 token 重放；刷新会话或等待切租户完成 |
| 403 `TENANT_ROLE_FORBIDDEN` | 不重试，保留登录状态并提示无权限 |
| 400 `TENANT_REQUIRED` | 引导选择或创建租户，不自行补 `tenant_id` |
| 404 `TENANT_NOT_FOUND` | 刷新租户列表 |
| 404 `RESOURCE_NOT_FOUND` | 当作不可见或不存在，不换 ID 重试 |

## Smoke Checklist

- [ ] 登录后保存完整 `AuthSession`，业务请求带 Bearer。
- [ ] 刷新后旧 token 不能继续使用。
- [ ] 切租户后替换会话，清旧缓存并关闭旧 SSE。
- [ ] 创建租户时不发送服务端字段。
- [ ] A 租户不能查看、修改或删除 B 租户的文件和项目资源。
- [ ] KnowledgeFile 下载、预览走后端接口。
- [ ] Project、Tender、AuditTask 的列表和详情随当前租户变化。
- [ ] 403 不自动重试，404 不用于探测其他租户资源。
- [ ] 浏览器请求中没有内部租户或签名 Header。
