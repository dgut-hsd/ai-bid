启动步骤有依赖顺序。端口和链路如下：

```
前端 React :5173  →  Java :3000  →  Rust :3001
                          ↓
                   MySQL 8 + Redis 7
```

（根目录 `.env` 已配好 DashScope API Key，且 `EMBED_ENGINE=remote`，因此**无需下载 568MB 模型**。）

## 启动步骤（按顺序）

**1. 起 MySQL + Redis**（Java 的依赖）
```powershell
docker compose -f backend-java/src/main/resources/docker-compose.yml up -d mysql redis
```
> 该 compose 里还有 Milvus/Qdrant/Neo4j 等，Java 只用 MySQL 和 Redis，所以只 up 这两个即可。数据库名 `smart_tender_system`，root/1234 已由镜像自动创建。

**2. 起 Rust 引擎（:3001）**
```powershell
cd backend-rust
cargo run --bin server
```

**3. 起 Java 后端（:3000）**
```powershell
cd backend-java
mvn spring-boot:run
```
> 配置文件 `spring.profiles.active=prod`，端口 3000。也可以打包运行：`mvn clean package -DskipTests && java -jar target/smart_tender-0.0.1-SNAPSHOT.jar`

**4. 起 React 前端（:5173）**
```powershell
cd frontend
pnpm install       # 首次运行
pnpm dev
```

浏览器打开 **http://localhost:5173/login**，SQL种子：默认账号13800138000，密码 123456。也可以自己注册登录。

## 注意
- 依赖顺序不能乱：MySQL/Redis → Rust → Java → 前端（前端 `/api` 反向代理到 Java:3000，Java 再代理 AI 请求到 Rust:3001）。
